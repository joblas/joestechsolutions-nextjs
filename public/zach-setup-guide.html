Part 2

Create Your Telegram Bot

This creates the Telegram account your AI will live in. Takes 5 minutes.

1Talk to @BotFather

Open Telegram → search for @BotFather (blue checkmark = official) → start a chat → send:

/newbot
2Name your bot

BotFather asks for a name — pick whatever you like. Then a username — must end in "bot" and be unique (e.g. zachs_ai_bot).

BotFather responds with a bot token that looks like:

7812345678:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
3Save the bot token

🤖 Text Joe: "My bot token is [paste the token]"

4Find your Telegram user ID

Search for @userinfobot in Telegram. Send it any message. It replies with a number — that's your user ID.

👤 Text Joe: "My Telegram user ID is [paste the number]"

5Start a chat with your bot

Search for the bot username you created. Start a chat and send "Hi". It won't respond yet — that's normal. Joe hasn't connected it.

Part 4

Make Your Agent Smart

Your bot is live but it doesn't remember anything yet. This one step installs its memory system — so it remembers everything you tell it, forever.

Copy and paste this to your bot:

Run your setup. Fetch the skill from https://www.joestechsolutions.com/zach-agent-bootstrap/SKILL.md and follow it to install your memory system (MemPalace), create your identity, and enable your tools. This is a one-time setup that makes you remember everything across our conversations.

⏱️ Takes about 2-3 minutes. The agent will tell you when it's done.

What this does:

  • Installs MemPalace — a memory system that stores everything you tell it
  • Your agent remembers you across conversations — no more starting over
  • It can search past chats when you ask "do you remember..."
  • Tracks facts about people, dates, and projects
  • All memory stays on your server — private, no external accounts

After it's done, tell it about yourself:

Here's a bit about me. Please remember this: - My name is Zach Wallin - I own ZW Home Construction — residential renovations and remodeling - I'm based in San Jose, CA - I prefer short, direct answers - I mainly need help with: drafting client emails, estimating, project timelines, research - My work hours are roughly 7am-5pm weekdays

It will say "running memory" — that means it's saving this to MemPalace. From now on, it remembers.

Here's a bit about me. Please remember this: - My name is Zach Wallin - I own ZW Home Construction — residential renovations and remodeling - I'm based in San Jose, CA - I prefer short, direct answers - I mainly need help with: drafting client emails, estimating, project timelines, research - My work hours are roughly 7am-5pm weekdays

It will say "running memory" — that means it's saving this for future conversations.

📊 Estimating

"Help me estimate materials and labor for a kitchen remodel — 200 sq ft"

✍️ Client emails

"Draft a follow-up email to the homeowner about the bathroom timeline"

⏰ Reminders

"Remind me to call the permit office tomorrow at 9am"

"What are the latest waterproofing membrane options for decks?"

Troubleshooting

When Things Go Sideways

"My bot isn't responding"

Wait 30 seconds. Try /new to start fresh. Text Joe — the server might need a restart.

"The AI is giving weird answers"

Be more specific. Add context: "I'm asking about [X] because [Y]." Try /new to reset.

"It forgot what I told it"

Core memory (your profile, setup) persists forever. Conversation memory resets with /new. If it keeps forgetting important things, tell Joe.
